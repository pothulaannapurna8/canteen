# SRKR Canteen Queue Management System

A comprehensive web-based canteen queue management system built with HTML5, CSS3, and JavaScript.

## Features

- **Owner Panel**: Menu management, queue processing, token generation
- **Kitchen Dashboard**: Real-time queue tracking, status updates
- **Student Status**: Token-based queue lookup and status display

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Design**: Responsive, mobile-first approach
- **Architecture**: Client-side with in-memory data storage

## Project Structure

```
canteen/
├── index.html          # Main application with all three modules
├── kitchen.html        # Standalone kitchen dashboard
├── status.html         # Standalone student status page
└── README.md           # Project documentation
```

## Usage

1. Open `index.html` in a web browser
2. Navigate between Owner, Kitchen, and Student tabs
3. Use the standalone pages for dedicated views
